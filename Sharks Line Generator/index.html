The included roster is sample data. Availability defaults to 100%; add | IN:70 for a 70% chance to make the lineup. Forwards can also include position and line weights: Name | RW:80, C:20 | L1:70, L2:25, L3:4, L4:1 | IN:70 | PHOTO:photos/name.jpg. Use Name | IN:70 | PHOTO:photos/name.jpg for a forward without position or line preferences. Defense can include side weights and defense-pair weights: Name | LD:100 | L1:80, L2:10, L3:10 | IN:75 | PHOTO:photos/name.jpg or Name | LD:80, RD:20. Pair weights control the chance of pairing one, two, or three. Goalies use Name | IN:15 | PHOTO:photos/name.jpg. Put images in a photos folder next to this page, or use an image URL. Since the lineup has fixed sizes, availability odds must total 1200% for forwards, 600% for defense, and 100% for goalies. For example, 11 guaranteed forwards plus a 70% player and a 30% replacement total 1200%. Players without a photo path show an initials placeholder.
